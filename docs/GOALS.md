# Goals

## Purpose

TaskSorter generates a ranked, read-only queue of GitHub issues and pull requests across personal repositories.

## Current Phase

Make the CLI practical for daily 1-2 hour personal project sessions.

## Completed Outcomes

- Generate a top 5-10 task queue from GitHub Issues without modifying GitHub.
- Support cross-project priority through repository ordering and project tiers.
- Support lightweight task ranking through priority, type, status, and size labels.

## Next Outcomes

- Add a small sample configuration for personal projects that can be copied into a local-only setup.
- Improve report readability after real daily use.
- Consider optional label validation reports without changing GitHub.
